# Medusa Playwright Framework

Test automation framework for [Medusa](https://medusajs.com), an open-source headless e-commerce platform.

**Status:** work in progress.

## Tech Stack

- TypeScript
- Playwright

## Planned Test Coverage

- API tests for the Store and Admin REST APIs
- Integration tests
- UI / end-to-end tests for key user flows
- Unit tests for framework utilities
